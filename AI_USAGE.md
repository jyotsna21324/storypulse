# AI use and project ownership

This project was developed with AI assistance as a learning and productivity aid.

AI may be used for:
- Brainstorming the business problem and possible approaches.
- Explaining Python, SQL and analytics concepts during development.
- Reviewing code for edge cases and suggesting tests.
- Improving clarity of documentation.

The current version does not call an LLM or require an AI API. Core metrics, validation and review flags are implemented as transparent Python logic. The sample dataset is synthetic.

The project owner should review, run, test and understand the code before presenting it. Any future AI-generated interpretation should be labelled as a suggestion and reviewed by a person before being used for a business decision.
